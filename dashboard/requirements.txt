#

#   streamlit       — Interactive data dashboard framework (>=1.46 needed for width="stretch")

#   numpy           — Simulated demo trend generation (imported directly by pages)
#   plotly          — Interactive charts (AQI trends, forecast bands, HCHO trends)
#   python-dotenv   — Load dashboard/.env (VAYU_API_URL) in local development
#   folium          — Leaflet maps (stations, hotspots, fires)
#   branca          — Map legend HTML elements (imported directly by components/map.py)
#   streamlit-folium — Render folium maps inside Streamlit
